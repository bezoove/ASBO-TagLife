# ASBO: Life on Tag — Unity port

Unity 6.3 LTS (6000.3.29f1), URP. Copy `Assets/`, `ProjectSettings/`, `Packages/` into a fresh Unity project folder.
Slice scripts in `Assets/Scripts/Slice`. Placeholder voices (Kokoro TTS, Apache-2.0) in `Assets/Resources/Voices`.
Browser game source of truth for systems/data to port: `www/index.html` (v95).
Targets: Android first, devices up to ~5 years old, near-AAA look.
